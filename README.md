# Lídia Bonim — Portfólio

Este é o meu portfólio pessoal, criado do zero com **HTML, CSS e JavaScript puro**, sem frameworks ou bibliotecas. Nele reuni quem eu sou, minhas competências e minha jornada, e usei o próprio site como demonstração prática do que sei fazer.

O projeto reflete o que eu valorizo: simplicidade, criatividade e conexão com as pessoas. Está em constante evolução, assim como eu.

🔗 **Ao vivo:** https://lidiabonin-dev.github.io

## Seções do site

- **Sobre mim:** minha apresentação e o que me move.
- **Competências:** HTML, CSS e JavaScript em destaque, com demonstração ao vivo.
- **Jornada:** linha do tempo da minha trajetória.
- **Fora do trabalho:** meus interesses e hobbies.
- **Contato:** formas de falar comigo.

## Funcionalidades

- Layout responsivo, pensado para celular e computador.
- Tema claro e escuro, com a escolha salva no navegador.
- Seletor de cor ao vivo: o fundo, os cartões e os detalhes mudam com a cor escolhida.
- Efeito de digitação e partículas interativas em canvas.
- Barra de progresso de leitura e menu que acompanha a rolagem.
- Animações que aparecem conforme a página é rolada.
- Botão para copiar o e-mail com um clique.

## Tecnologias

- **HTML:** estrutura semântica e acessível (seções, navegação, ARIA).
- **CSS:** Grid, Flexbox, variáveis, animações, temas e responsividade.
- **JavaScript:** manipulação do DOM, eventos, Canvas, IntersectionObserver e localStorage.

## Estrutura

```
index.html   estrutura da página
style.css    visual e responsividade
script.js    interações
```

## O que este projeto mostra

Domínio da base da web sem depender de frameworks, atenção a detalhes de design e usabilidade, e vontade de aprender e evoluir a cada versão.
