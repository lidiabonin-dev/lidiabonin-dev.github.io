# Lídia Bonim — Portfólio

Site pessoal feito com **HTML, CSS e JavaScript puro**, sem frameworks ou bibliotecas.

🔗 **Ao vivo:** https://lidiabonin-dev.github.io

## O que tem no projeto

- **HTML:** estrutura semântica e acessível (seções, navegação, ARIA).
- **CSS:** Grid, Flexbox, variáveis, animações, tema claro/escuro e layout responsivo (celular e computador).
- **JavaScript:** efeito de digitação, partículas em canvas, barra de progresso, animações ao rolar (IntersectionObserver), seletor de cor ao vivo, troca de tema e botão de copiar e-mail.

## Estrutura

```
index.html   estrutura da página
style.css    visual e responsividade
script.js    interações
```

## Como rodar localmente

Baixe os arquivos e abra o `index.html` no navegador. Não precisa instalar nada.
